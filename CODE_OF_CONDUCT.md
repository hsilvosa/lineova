# Code of conduct

lineova is a small project and wants to stay a friendly one.

- Be respectful and constructive. Criticise code and ideas, not people.
- Assume good intent, and ask before assuming.
- No harassment, discrimination or personal attacks, in any form or channel connected to the project.
- Help newcomers. Everyone started somewhere.

Maintainers may remove comments, commits or contributions that break these rules, and may block people who repeatedly do so. To report a problem privately, contact the maintainer through their GitHub profile ([@hsilvosa](https://github.com/hsilvosa)).
